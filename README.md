# Wedding Booth

โปรแกรมตู้ถ่ายรูปงานแต่ง: ถ่าย พิมพ์ DNP และส่งรูปให้แขกผ่าน QR
Photo booth software for weddings: shoot, print on a DNP and send photos to guests by QR.

## ดาวน์โหลด / Download

**[ดาวน์โหลดตัวติดตั้งล่าสุด / Latest installer](https://github.com/JenCoolZa/WeddingBooth/releases/latest)** (Windows 10 / 11, 64-bit)

1. โหลดไฟล์ `Wedding.Booth.Setup.<เวอร์ชัน>.exe` แล้วเปิดติดตั้ง / Download the `.exe` and run it
2. สมัครฟรี / Sign up free: https://weddingbooth.sumet-phaladech.workers.dev/signup
3. เปิดโปรแกรมแล้วล็อกอินด้วยบัญชีเดียวกัน / Open the program and sign in with the same account

แพ็กเกจและวิธีชำระเงิน / Packages and payment: https://weddingbooth.sumet-phaladech.workers.dev
